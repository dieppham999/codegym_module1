ORION RADAR RECOVERY - BÁO CÁO XỬ LÝ LỖI
==========================================

1. NGUYÊN NHÂN LỖI TRONG LEGACY CODE
------------------------------------
- Truy cập thuộc tính x của phần tử null/undefined -> TypeError, làm dừng toàn bộ vòng render.
- Không kiểm tra API trả về mảng -> gọi forEach/map trên null hoặc chuỗi gây TypeError.
- Tọa độ NaN/Infinity/chuỗi không gây ngoại lệ trong arc() nhưng vẽ sai hoặc không vẽ -> lỗi "im lặng".
- try...catch đặt bên ngoài vòng lặp -> một phần tử lỗi làm bỏ qua toàn bộ phần tử còn lại.

2. GIẢI PHÁP
------------
- cleanData(raw): nếu raw không phải mảng -> console.warn, trả về danh sách rỗng.
- Mỗi phần tử được kiểm tra trong try...catch RIÊNG (bên trong forEach):
    + phải là object, không null, không phải mảng
    + id là string hoặc number
    + có đủ x và y
    + x, y là number hữu hạn (Number.isFinite) -> loại NaN, Infinity, null, undefined, chuỗi
    + nằm trong phạm vi radar
  Phần tử hỏng bị loại và ghi console.warn kèm lý do và dữ liệu gốc.
- Vòng loop() của requestAnimationFrame bọc try...catch và luôn gọi requestAnimationFrame
  ở cuối -> khung hình lỗi không làm dừng radar.
- drawPlanes() có try...catch riêng cho từng máy bay.

3. DỮ LIỆU KIỂM THỬ LỖI
-----------------------
Mảng hỗn hợp 13 phần tử:
  {id:"A",x:300,y:300}      -> HỢP LỆ
  null                      -> loại: phần tử không phải object (null)
  undefined                 -> loại: phần tử không phải object (undefined)
  {id:"B",x:NaN,y:1}        -> loại: tọa độ không hợp lệ
  {id:"C",x:1,y:Infinity}   -> loại: tọa độ không hợp lệ
  {id:"D",x:"300",y:300}    -> loại: sai kiểu (chuỗi)
  {id:"E",x:300}            -> loại: thiếu tọa độ x/y
  {x:300,y:300}             -> loại: thiếu hoặc sai kiểu id
  "X"                       -> loại: không phải object
  42                        -> loại: không phải object
  [1,2]                     -> loại: sai cấu trúc (mảng)
  {id:"F",x:9999,y:300}     -> loại: ngoài phạm vi radar
  {id:7,x:310,y:290}        -> HỢP LỆ (id số được chuyển thành chuỗi "7")

Dữ liệu API sai cấu trúc: null, undefined, "500 Error", {data:[]}, 404.

Dữ liệu stress: 500 máy bay, mỗi phần tử có xác suất 30% bị làm hỏng ngẫu nhiên
bằng 1 trong 14 kiểu lỗi (null, undefined, NaN, ±Infinity, chuỗi, thiếu id, thiếu y,
mảng, số, ngoài phạm vi...).
