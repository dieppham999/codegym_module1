# Ứng dụng máy tính (JavaScript Calculator)

## Giới thiệu

Dự án bài tập CodeGym xây dựng ứng dụng máy tính đơn giản bằng HTML, CSS và JavaScript, giúp thực hành biến, toán tử, biểu thức, hàm và thao tác với form.

## Mục tiêu

- Sử dụng các khái niệm cơ bản của JavaScript: biến, toán tử, biểu thức và hàm.
- Lấy dữ liệu người dùng nhập từ form và hiển thị kết quả tính toán.
- Xử lý sự kiện nhấn nút để thực hiện phép tính.

## Yêu cầu chức năng

- Nhập hai số từ giao diện.
- Thực hiện bốn phép tính: cộng (`+`), trừ (`-`), nhân (`×`) và chia (`÷`).
- Hiển thị kết quả tương ứng khi người dùng nhấn nút phép tính.
- Kiểm tra dữ liệu nhập và xử lý trường hợp chia cho 0.

## Các bước thực hiện

1. Tạo giao diện bằng HTML với các thẻ `<form>`, `<input>` và `<button>`.
2. Viết bốn hàm JavaScript lấy dữ liệu từ form, thực hiện phép tính và trả về kết quả.
3. Gắn sự kiện cho các nút để gọi hàm tương ứng.

## Yêu cầu mở rộng

1. Tìm cách dùng một hàm duy nhất để xử lý cả bốn phép tính.
2. Nâng cấp giao diện và chức năng theo hướng máy tính Google Calculator.

## Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Cấu trúc dự án

```text
javascript-calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

> Cấu trúc trên là kế hoạch triển khai; các file giao diện và JavaScript sẽ được bổ sung trong quá trình thực hiện.

## Chạy dự án

Sau khi tạo `index.html`, mở file bằng trình duyệt hoặc dùng tiện ích Live Server trong VS Code.
